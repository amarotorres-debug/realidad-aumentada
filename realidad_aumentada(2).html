¿Qué es la Realidad Aumentada?

Tecnología para ampliar nuestra percepción del entorno.

La Realidad Aumentada (RA) permite visualizar información digital sobre el mundo real mediante dispositivos como celulares, tablets, cámaras y otros sistemas electrónicos.


Por ejemplo, una cámara puede reconocer una imagen y mostrar sobre ella un modelo 3D, una animación, un texto o un video interactivo.

🥽✨

Aplicaciones

La RA puede utilizarse en diferentes áreas.

🎓

Educación

Permite aprender mediante modelos, animaciones y contenidos interactivos.

🎮

Entretenimiento

Combina elementos virtuales con espacios reales para crear experiencias inmersivas.

🏭

Industria

Puede apoyar procesos de capacitación, mantenimiento y visualización de información.

🩺

Salud

Puede utilizarse para visualizar información y apoyar procesos de formación.

¿Cómo funciona?

Un proceso que combina sensores, software y contenido digital.

Captura del entorno

La cámara del dispositivo observa el espacio o una imagen de referencia.

Reconocimiento

El software identifica una imagen, superficie u objeto que sirve como referencia.

Procesamiento

El sistema calcula dónde y cómo colocar el contenido digital.

Visualización

El usuario observa imágenes, modelos, textos o videos integrados al entorno real.

Realidad Aumentada + Electrónica

Una combinación de tecnología, programación y creatividad.

🔌

Dispositivos

La electrónica permite construir y utilizar sistemas con sensores, cámaras, microcontroladores y otros componentes.

💻

Programación

El software procesa la información y controla la interacción entre el usuario y los contenidos digitales.

📡

Interacción

Los sensores y sistemas electrónicos pueden aportar datos para crear experiencias más interactivas.
